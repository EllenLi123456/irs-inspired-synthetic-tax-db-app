# Relational Database Development SKILL

**Status: Work in Progress (Planning Stage)**

## Overview

This planned SKILL will transform the lessons and development workflow from the CS 727 IRS Database Project into a reusable, AI-assisted process for building relational database applications.

## Planned Capabilities

- Guide relational database requirements and ERD design.
- Support database schema creation and normalization.
- Generate synthetic test datasets.
- Develop and explain SQL queries and analytics.
- Guide Python and Flask application development.
- Support testing, documentation, and GitHub portfolio preparation.

## Development Status

This SKILL has not yet been implemented. Its design and development are planned as a future extension of this project.

The long-term goal is to make the workflow reusable for database projects beyond the IRS-inspired application.
